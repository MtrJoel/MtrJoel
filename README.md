## 🚀 Proyectos destacados

### 🎓 Quorom Académico

**Spring Boot · React · PostgreSQL · Docker**

Plataforma full-stack creada para resolver un problema real en el entorno universitario: organizar las solicitudes de asignaturas y horarios de los estudiantes.

* API REST desarrollada con Spring Boot.
* Gestión de datos mediante PostgreSQL.
* Interfaz web construida con React.
* Despliegue del backend con Docker y Render, y del frontend con Vercel.
* Propuesta presentada formalmente ante la dirección universitaria.

🔗 **[Ver demo en vivo](https://solicitud-asignaturas-frontend.vercel.app/)** · [Ver detalles del proyecto](https://joel-montero-porfolio.onrender.com/)

### 📝 Smart Notes — Chrome Extension

**JavaScript · Chrome Extensions · Manifest V3**

Extensión publicada en Chrome Web Store para guardar notas y fragmentos importantes mientras navegas por Internet.

* Guardado y organización de notas contextuales.
* Persistencia local mediante Chrome Storage APIs.
* Herramienta orientada a estudiantes, lectores y personas que buscan mejorar su productividad.

🔗 [Instalar desde Chrome Web Store](https://chromewebstore.google.com/detail/smart-notes/aopgmpnlbjpgnnnhpdidjkhcbgbdflnc?hl=es) · [Ver código fuente](https://github.com/MtrJoel/smart-notes)

### 🏦 Backend Core Bancario & API Transaccional

**Java · Spring Boot · SQL Server · Spring Data JPA**

API REST orientada a simular operaciones bancarias, gestionar cuentas y mantener un registro de las transacciones.

* Procesamiento de transferencias con control de concurrencia.
* Persistencia relacional mediante Spring Data JPA.
* Enfoque en consistencia de datos y atomicidad transaccional.

### 🚗 Sistema de Gestión de Peaje

**Java · Programación Orientada a Objetos · SQL**

Sistema backend para procesar cobros en estaciones de peaje, validar saldos y calcular tarifas según las características del vehículo.

* Aplicación de reglas de negocio para el cálculo de tarifas.
* Validación de fondos disponibles.
* Actualización de balances y control de operaciones.

### 📱 betHabits

**Flutter · Dart**

Aplicación móvil multiplataforma para realizar seguimiento de hábitos, registrar rachas y fomentar la constancia personal.

* Seguimiento de hábitos y progreso.
* Mecánicas de compromiso personal.
* Separación de responsabilidades entre dominio, datos y estado de la aplicación.
